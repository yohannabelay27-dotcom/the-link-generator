TIME-LIMIT LINK GENERATOR (for the owner only)
1. Log in at app.netlify.com, then go to app.netlify.com/drop and drag index.html onto the page.
2. Open the site link on your phone/computer.
3. Paste your invitation website link, enter the customer name and the expiry date, tap "Generate".
4. Give the generated link to the customer. Give the EVENT CODE to the gate staff.

IMPORTANT: Do NOT share this site's link with anyone. Anyone who opens it can create customer links.
Use a hard-to-guess site name (Site configuration > Change site name), e.g. gen-7k2m9x-private.
To update later: Netlify > your site > Deploys > drag the new index.html.
